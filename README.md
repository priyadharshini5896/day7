# Basic Sales Summary with SQLite & Python
  This is a simple project that shows how to work with an SQLite database in Python to summarize and visualize basic sales data.

# Requirements
  1.Python 3.x
  2.pandas
  3.matplotlib

# Explanation
  First, it creates a small database with a few sample sales records. Then, it analyzes the data. Finally, it prints the results and displays a simple bar chart so you can quickly see which product earned the most.
